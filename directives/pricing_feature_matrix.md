# Directive: Pricing Feature Matrix Comparison Table

## Objective
Provide an exhaustive, crisp, two-segment comparison matrix for IFA Media's pricing packages:
- **Segment 1**: Website Features
- **Segment 2**: Digital Marketing Features

Comparison columns:
1. **Feature Title**: Concise, punchy title (2-5 words)
2. **Hover Explainer**: 1-line tooltip explainer revealed on hover over the `(i)` info icon
3. **Basic (Starter Plan)**: Checkmark `✓` or blank
4. **Advanced (Growth Plan)**: Checkmark `✓` or blank

## Deliverables
- Google Sheets Importable CSV & TSV in `.tmp/`:
  - `.tmp/ifa_media_google_sheets_paste.tsv` (Direct clipboard paste into Google Sheets)
  - `.tmp/ifa_media_google_sheets_import.csv` (File -> Import into Google Sheets)
- Next.js Component in `src/components/marketing/` to render the comparison table on the live site with tooltip hover states and responsive layout.
